# SolidWorks for Codex

این پروژه، فایل ZIP اولیه را به یک افزونه‌ی محلی Codex همراه با MCP سرور واقعی SolidWorks تبدیل می‌کند. Codex می‌تواند اسکچ و ویژگی‌ها را به SolidWorks بفرستد؛ پنجره‌ی SolidWorks باز می‌ماند و هر مرحله با یک فراخوانی جدا، جلوی کاربر ساخته می‌شود.

## نصب سریع

در PowerShell و از ریشه‌ی پروژه:

```powershell
.\plugins\solidworks-codex\scripts\install.ps1 -InstallInCodex
```

بعد Codex را دوباره باز کنید. مراحل نصب، محیط مجازی محلی، وابستگی‌ها و وضعیت ثبت COM را آماده می‌کند. Codex برای نصب افزونه به این دو فایل محلی تکیه می‌کند: `.agents/plugins/marketplace.json` و `plugins/solidworks-codex/`.

## بررسی و تحلیل منابع

جزئیات بررسی ZIP و سه مخزن، تصمیم‌های معماری، مجوزها و محدودیت‌های نسخه در [SOURCES.md](SOURCES.md) آمده است. پیاده‌سازی مستقل است؛ از کد مخزن AGPL کپی نشده.

## پوشش فعلی

اتصال COM سریالی روی نخ STA، ساخت Part/Assembly خالی، بازکردن فایل بومی، اسکچ خط/مستطیل/دایره/کمان، Boss-Extrude، Cut-Extrude، مشاهده‌ی درخت ویژگی، اعتبارسنجی rebuild، mass properties، نماها و ذخیره را پوشش می‌دهد. اندازه‌ها به میلی‌متر هستند مگر واحد دیگری صریح شود و پیش از رسیدن به COM به متر تبدیل می‌شوند.

محدودیت‌های مشخص نسخه‌ی فعلی: mate اسمبلی، drawing، sheet metal، pattern، dimension و خروجی STEP هنوز پیاده‌سازی نشده‌اند. افزونه تا وقتی ابزار اعتبارسنجی برای آن workflowها اضافه و در SolidWorks واقعی اجرا نشده باشد، آن‌ها را پوشش‌داده‌شده اعلام نمی‌کند.
