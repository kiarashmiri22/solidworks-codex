# SolidWorks for Codex

افزونه‌ی محلی Codex به SolidWorks واقعی وصل می‌شود. سرور MCP روی همین ویندوز اجرا می‌شود و عملیات را از طریق COM انجام می‌دهد؛ برنامه‌ی SolidWorks جلوی کاربر باز و قابل مشاهده می‌ماند. هر ترسیم و هر ویژگی یک فراخوانی جداست تا ساخت مدل مرحله‌به‌مرحله دیده شود.

## نصب

از ریشه‌ی پروژه اجرا کنید:

```powershell
.\plugins\solidworks-codex\scripts\install.ps1
```

این دستور محیط Python محلی افزونه را می‌سازد، وابستگی‌ها را نصب می‌کند و پیش‌نیازهای ویندوز و COM را بدون بازکردن SolidWorks بررسی می‌کند. برای ثبت و نصب افزونه در Codex:

```powershell
.\plugins\solidworks-codex\scripts\install.ps1 -InstallInCodex
```

سپس Codex را ببندید و دوباره باز کنید. پروژه باید trusted باشد تا marketplace محلی آن بارگذاری شود. `.codex/config.toml` همین پروژه افزونه را برای این مخزن فعال می‌کند.

اگر نصب دستی می‌خواهید:

```powershell
codex plugin marketplace add .
codex plugin add solidworks-codex@solidworks-local
```

## نمونه‌ی درخواست

```text
یک قطعه با واحد میلی‌متر بساز: روی صفحه Front مستطیل 50×30 بکش و 10 میلی‌متر اکسترود کن.
مرحله‌ها را جداگانه اجرا کن تا در SolidWorks ببینم و در پایان درخت ویژگی و rebuild را بررسی کن.
```

SolidWorks باید روی ویندوز نصب و COM آن ثبت شده باشد. سرور از قالب پیش‌فرض Part/Assembly/Drawing تنظیم‌شده در SolidWorks استفاده می‌کند؛ مسیر قالب در کد ثابت نشده است. اگر چند پنجره‌ی SolidWorks باز باشد، `sw_status` عنوان پنجره و شناسه‌ی هر پردازه را نشان می‌دهد و Codex باید قبل از مدل‌سازی از کاربر بپرسد کدام پنجره را انتخاب کند. فقط پردازه‌هایی که `registered_with_com: true` دارند قابل انتخاب‌اند. سپس `sw_ensure_ready(instance_pid=...)` دقیقاً به COM همان پردازه متصل می‌شود؛ نمونه‌ی دومی باز نمی‌شود.

## ابزارهای این نسخه

- اتصال و وضعیت SolidWorks، فهرست سندهای باز، ساخت Part/Assembly/Drawing و بازکردن فایل بومی.
- اسکچ روی صفحه‌ی مرجع یا Face انتخاب‌شده، خط، مستطیل، دایره، کمان سه‌نقطه‌ای و چندضلعی منظم.
- پایان اسکچ با برگرداندن نام دقیق آن، Boss-Extrude و Cut-Extrude کور یا Through All.
- فهرست‌کردن اجزای اسمبلی و درج Part/Subassembly با مختصات، بدون ادعای ساخت Mate.
- مشاهده‌ی درخت ویژگی، rebuild و mass properties، نماهای استاندارد، ذخیره‌ی امن و خروجی STEP/IGES/STL.

Drawing فقط از قالب پیش‌فرض ساخته می‌شود؛ ساخت Sheet و View و Dimension در Drawing، Mate اسمبلی، Sheet Metal، Pattern، Hole Wizard و ویرایش دلخواه Featureها هنوز پیاده‌سازی نشده‌اند. خروجی STEP/IGES/STL به انتخاب فایل فعال و قالب خروجی نصب‌شده وابسته است؛ نتیجه‌ی هر خروجی را در SolidWorks یا نرم‌افزار مقصد بررسی کنید.

## حریم داده

هیچ مدل، مختصات، فایل یا سابقه‌ای به سرویس بیرونی ارسال نمی‌شود. وابستگی‌ها فقط هنگام نصب Python از PyPI دریافت می‌شوند. نصب خودکار اولین اجرا هم همین وابستگی‌های ثبت‌شده را نصب می‌کند؛ اجراهای بعدی شبکه لازم ندارند.
