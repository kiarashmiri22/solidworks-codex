# Changelog

## 0.2.0

- Added drawing creation, open-document listing, face-based sketch start, and regular polygon sketches.
- Added assembly component listing and explicit-coordinate component insertion.
- Added STEP, IGES, and STL export for active parts and assemblies.
- Updated native save operations to use `Save3` and `SaveAs3` with COM-safe optional out parameters.
- Updated the design workflow and documented features that still need implementation or SolidWorks-side verification.
